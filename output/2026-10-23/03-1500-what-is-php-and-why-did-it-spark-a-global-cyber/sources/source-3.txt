A security researcher has demonstrated a software-only partial jailbreak of the Switch 2, gaining “userland” access that he says “lets us run homebrew, reverse engineer and mod Switch 2 games, back up save files off the Switch, and access most of the Switch 2’s peripherals through MMIO.”
The hack relies on the original Switch version of SmileBasic 4, the latest in a long-running series of programming environments and interpreters that run on Nintendo hardware. The so-called “tethered” hack also requires access to a macOS or Linux PC on the same network to run a node.js package that helps enable privileged system access.
Researcher Sammy Hajhamid writes that he used OpenAI’s Codex to poke at SmileBasic’s language interpreter, using a custom harness that could send USB commands to the system and view results via HDMI (as well as power cycling via a Bluetooth light switch flipping device). After “substantial effort for ~2 weeks,” that harness discovered a 32-bit integer overflow that occurs when removing items from an array in SmileBasic. That error gives access to an array pointer, which in turn allows read and write access to portions of system memory.
From there, Hajhamid writes that he started poking around for access to the Switch 2’s internal sysmodules, looking for ones that could provide more privileged access to the console’s core functions. Eventually, he found a buffer overflow in the console’s FileSystem services module that exposed a cached data pointer, granting arbitrary read and write privileges. From there, Hajhamid writes that he could execute “privileged filesystem actions” and eventually achieve native code execution through a faked filesystem process.
Hajhamid, who goes by Pepsipu online, showed off a host of new modded characters in Mario Kart World as a proof of concept for the exploit. Others are similarly showing off simple demos and in-progress developer tools running on exploited hardware.
